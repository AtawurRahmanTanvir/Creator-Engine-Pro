🚀 Basic Setup:

  1. Select a profile (e.g., Normal_Browser) from the Account Switcher.
  2. Start the required AI Engines (e.g., Administrator, ChatGPT, Final).
  3. Wait for the console to show "Ready" before sending prompts.

🧠 Advanced AI-to-AI Routing:

This workspace allows AIs to communicate! Use these tags in your prompts:

  • @administrator : The Boss AI. Manages and assigns tasks.
  • @chatgpt, @claude, @gemini : The Worker AIs.
  • @final : The Editor AI. Polishes and delivers output.

⚙️ Step 1: Train the Final AI

Target Final in the input box and send this to set its rules:

"System Prompt: Act as the 'Final Editor AI'. Review content from @administrator, polish it, and ALWAYS add the tag @admin at the very end of your output. Reply with '@admin System Ready' if you understand."

🎯 Step 2: Trigger Automation

Target Administrator AI and give a multi-agent task like:

"Ask @chatgpt to write a 2-line motivational quote. When received, check grammar and send to @final for polishing."
